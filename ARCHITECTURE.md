# Архитектура CareerHub

Проект организован как монорепозиторий из трёх независимых приложений:

```text
CareerHub/
├── backend/        # Django REST API, бизнес-логика и база данных
│   ├── account/    # доменное Django-приложение
│   ├── core/       # настройки и маршрутизация Django
│   └── manage.py
├── frontend/       # React + Vite клиент
│   ├── public/
│   └── src/
├── ai/             # изолированный FastAPI-сервис генерации summary
│   ├── prompts/
│   ├── tests/
│   └── main.py
├── scripts/        # общие сценарии разработки
└── .env            # общая локальная конфигурация сервисов
```

## Границы сервисов

- `frontend` общается только с HTTP API Django и не импортирует код backend.
- `backend` содержит данные, авторизацию и бизнес-логику. К AI обращается по `AI_SERVICE_URL`.
- `ai` не имеет доступа к моделям Django и базе данных. Он принимает только необходимые данные через HTTP.
- Каждый сервис хранит собственные зависимости и тесты в своей директории.

Такое разделение позволяет собирать, тестировать и развёртывать части проекта независимо.
