# Кнопки и элементы управления CareerHub

Документ описывает кнопки, кликабельные карточки, ссылки и переключатели текущей версии сайта. Доступность отдельных элементов зависит от роли пользователя: студент, соискатель или компания.

## 1. Главная страница

| Элемент | Действие |
|---|---|
| **Войти в систему** | Открывает страницу авторизации. |
| **Для студентов / Войти как студент** | Открывает двухэтапную регистрацию студента. |
| **Для соискателей / Начать поиск** | Открывает регистрацию соискателя. |
| **Для компаний / Зарегистрировать компанию** | Открывает регистрацию компании. |
| **Подключить NCALayer** | Закрывает информационное окно ЭЦП. Реальное подключение к NCALayer пока не реализовано. |
| **Отмена** в окне ЭЦП | Закрывает окно без продолжения. |

## 2. Авторизация

| Элемент | Действие |
|---|---|
| **Назад** | Возвращает на предыдущую страницу. |
| **Студент** | Выбирает вход в роли студента. |
| **Соискатель** | Выбирает вход в роли соискателя. |
| **Компания** | Выбирает вход в роли компании. |
| **Глаз в поле пароля** | Показывает или скрывает введённый пароль. |
| **Войти в аккаунт** | Проверяет форму, отправляет email и пароль в API и открывает раздел соответствующей роли. |
| **Зарегистрироваться** | Возвращает на главную страницу, где можно выбрать тип аккаунта. |
| **Забыли пароль?** | В текущей версии обработчик восстановления пароля ещё не подключён. |

## 3. Регистрация

### Регистрация студента

| Элемент | Действие |
|---|---|
| **Назад** | На первом шаге возвращает на главную; на втором — к выбору университета и вводу Student ID. |
| **Выбор университета** | Открывает или закрывает список университетов. |
| **Название университета в списке** | Выбирает университет и закрывает список. |
| **Продолжить** | Проверяет первый шаг и открывает ввод имени, email и пароля. |
| **Глаз в поле пароля** | Показывает или скрывает пароль. |
| **Создать аккаунт** | Валидирует данные, регистрирует студента, выполняет вход и открывает профиль. |
| **Войти** | Открывает страницу авторизации. |

### Регистрация соискателя

| Элемент | Действие |
|---|---|
| **Назад** | Возвращает на главную страницу. |
| **Глаз у пароля** | Показывает или скрывает пароль. |
| **Глаз у подтверждения пароля** | Показывает или скрывает повторно введённый пароль. |
| **Создать аккаунт** | Проверяет форму, регистрирует соискателя и открывает профиль. |
| **Войти** | Открывает страницу авторизации. |

### Регистрация компании

| Элемент | Действие |
|---|---|
| **Назад** | Возвращает на главную страницу. |
| **Глаз у пароля** | Показывает или скрывает пароль. |
| **Глаз у подтверждения пароля** | Показывает или скрывает подтверждение. |
| **Зарегистрировать компанию** | Проверяет данные, создаёт аккаунт компании и выполняет вход. |
| **Войти** | Открывает авторизацию с заранее выбранной ролью компании. |

## 4. Верхнее меню после входа

| Элемент | Действие |
|---|---|
| **Логотип CareerHub** | Для компании открывает «Мои вакансии»; для кандидата — список вакансий. |
| **Вакансии** | Открывает список вакансий кандидата либо управление вакансиями компании. |
| **Мои отклики** | Для студента и соискателя открывает историю откликов, ответы компаний и последние уведомления. Красный счётчик показывает количество непрочитанных ответов. |
| **Тесты** | Для студента и соискателя открывает тестирование навыков. |
| **Кандидаты** | Для компании открывает базу кандидатов. |
| **Профиль** | Открывает профиль текущего пользователя. |
| **Выйти** | Удаляет токены авторизации и возвращает на главную. |
| **Меню ☰ / крестик** | Открывает или закрывает мобильное меню. |
| **Пункты мобильного меню** | Переходят в выбранный раздел и автоматически закрывают меню. |
| **Выйти из аккаунта** в мобильном меню | Завершает сессию и возвращает на главную. |

## 5. Первичное заполнение профиля

| Элемент | Действие |
|---|---|
| **Продолжить** | Проверяет телефон, сохраняет телефон, GitHub и признак завершённого профиля. |

## 6. Профиль студента или соискателя

### Основные данные

| Элемент | Действие |
|---|---|
| **Аватар** | Открывает выбор изображения и загружает новый аватар. |
| **Город** | Включает редактирование города. Enter или потеря фокуса сохраняет; Escape отменяет. |
| **Специализация / Добавить специализацию** | Включает редактирование желаемой должности. Enter или потеря фокуса сохраняет; Escape отменяет. |
| **Разрешить компаниям видеть мои контакты** | Включает или выключает доступ работодателей к email, телефону и GitHub. |
| **Скачать резюме** | Формирует PDF из данных профиля и скачивает его. |
| **Загрузить своё** | Открывает выбор PDF, DOC или DOCX и загружает готовое резюме. |
| **Открыть загруженное резюме** | Открывает ранее загруженный документ в новой вкладке. |
| **Удалить своё резюме** | После подтверждения удаляет загруженный файл. |
| **Удалить аккаунт** | Для соискателя удаляет профиль после подтверждения. Для студента кнопка скрыта. |

### Блок «О себе»

| Элемент | Действие |
|---|---|
| **Создать с ИИ** | Собирает специализацию, образование, навыки и проекты; через Django и NLP генерирует summary. Результат открывается для проверки и не сохраняется автоматически. |
| **Изменить** | Открывает ручное редактирование текста «О себе». |
| **Сохранить** | Сохраняет проверенный или отредактированный текст. |

### Опыт работы

| Элемент | Действие |
|---|---|
| **Изменить** | Включает редактирование списка опыта. |
| **Крестик у места работы** | Удаляет соответствующую запись. |
| **Добавить место работы** | Добавляет пустую форму новой записи. |
| **По настоящее время** | Указывает, что работа продолжается, и очищает дату окончания. |
| **Готово** | Проверяет обязательные поля и сохраняет опыт. |

### Проекты

| Элемент | Действие |
|---|---|
| **Изменить** | Включает редактирование проектов. |
| **Крестик у проекта** | Удаляет выбранный проект. |
| **Добавить проект** | Добавляет форму нового проекта. |
| **Готово** | Проверяет название, описание и технологии, затем сохраняет проекты. |

### Навыки и образование

| Элемент | Действие |
|---|---|
| **Навык из списка** | Добавляет навык в профиль или удаляет уже выбранный. |
| **Добавить навык** | Показывает поле для собственного навыка. Enter добавляет, Escape отменяет. |
| **Изменить образование** | Включает редактирование информации об образовании. |
| **Сохранить образование** | Сохраняет введённые данные и при наличии загружает диплом. |
| **Выбрать файл диплома** | Открывает системный выбор файла. |
| **Открыть диплом** | Открывает загруженный диплом в новой вкладке. |
| **GitHub** | Открывает профиль GitHub в новой вкладке. |

## 7. Профиль компании

| Элемент | Действие |
|---|---|
| **Аватар компании** | Открывает выбор и загрузку нового логотипа. |
| **Сайт** | Открывает сайт компании в новой вкладке. |
| **Удалить** | Удаляет аккаунт компании после подтверждения. |
| **Редактировать профиль** | Показывает форму названия, описания, города, отрасли, размера и сайта. |
| **Отмена** | Закрывает форму без сохранения новых изменений. |
| **Сохранить** | Отправляет изменения профиля компании в API. |
| **Управлять вакансиями** | Открывает страницу вакансий компании. |

## 8. Публичный список вакансий кандидата

| Элемент | Действие |
|---|---|
| **Подробнее и откликнуться** | Открывает полное описание выбранной вакансии. |
| **Назад к вакансиям** | Возвращает из карточки вакансии к списку. |
| **Откликнуться** | Создаёт отклик текущего кандидата. После успеха меняется на «Отклик отправлен» и блокируется. |

## 9. Поиск вакансий и компаний

| Элемент | Действие |
|---|---|
| **Карточка вакансии** | Открывает модальное окно с полным описанием. |
| **Обновить** | Повторно загружает вакансии из API. |
| **Фильтры** | Открывает или закрывает панель фильтров. |
| **Тип занятости** | Ограничивает список выбранным типом работы. |
| **Сбросить фильтры** | Очищает строку поиска и выбранный тип. |
| **Крестик / Закрыть** | Закрывает окно вакансии. Клик по затемнённому фону делает то же самое. |
| **Профиль компании** | Закрывает окно вакансии и открывает страницу работодателя. |
| **Назад к вакансиям** в профиле компании | Возвращает к предыдущему списку. |
| **Сайт / GitHub** | Открывает внешний ресурс компании. |

## 10. Управление вакансиями компании

| Элемент | Действие |
|---|---|
| **Создать вакансию** | Открывает трёхэтапную форму новой вакансии. |
| **Все / Активные / Пассивные** | Фильтрует вакансии по статусу. |
| **Активна / Пассивна** | Переключает публикацию конкретной вакансии. |
| **Отклики** | Загружает и показывает кандидатов, откликнувшихся на вакансию; повторный клик закрывает список. |
| **Статус отклика** | Меняет этап кандидата: новый, на рассмотрении, отклонён или нанят. |
| **Редактировать** | Открывает ту же трёхэтапную форму с текущими данными вакансии. |
| **Крестик формы** | Закрывает форму и возвращает её на первый шаг. |
| **Далее** | Проверяет текущий шаг и переходит к следующему. |
| **Назад** | Возвращает к предыдущему шагу. |
| **Отмена** | Закрывает форму на первом шаге. |
| **Опубликовать вакансию** | Создаёт вакансию после проверки всех полей. |
| **Сохранить изменения** | Обновляет редактируемую вакансию. |

## 11. База кандидатов компании

| Элемент | Действие |
|---|---|
| **Обновить** | Повторно загружает список кандидатов. |
| **Фильтры** | Показывает или скрывает фильтры. |
| **Все / Студент / Соискатель** | Фильтрует кандидатов по роли. |
| **Навык** | Добавляет или удаляет навык из API-фильтра. |
| **Сбросить фильтры** | Очищает поиск, роль и навыки. |
| **Посмотреть профиль** | Открывает подробный профиль кандидата. |
| **Пригласить на собеседование** | Отмечает приглашение как отправленное. Сейчас используется демонстрационный API без реальной отправки письма. |
| **Вернуться к списку** | Возвращает из профиля кандидата к базе. |
| **GitHub / диплом** | Открывает соответствующий внешний ресурс. |

## 12. Тестирование навыков

| Элемент | Действие |
|---|---|
| **Назад** в заголовке теста | Возвращает на страницу компаний/вакансий. |
| **Вариант ответа** | Выбирает один ответ для текущего вопроса. |
| **Точки вопросов** | Мгновенно переходят к выбранному вопросу. Заполненные вопросы выделяются. |
| **Назад** под вопросом | Переходит к предыдущему вопросу; на первом вопросе заблокирована. |
| **Далее** | Переходит к следующему вопросу; доступна после выбора ответа. |
| **Завершить тест** | Запускает анализ ответов и открывает результат. |
| **Крестик результата** | Закрывает окно результата. |
| **Пройти тест заново** | Очищает ответы и возвращает к первому вопросу. |
| **Карточка рекомендованного курса** | Открывает сайт INO в новой вкладке. |

Если время теста заканчивается, завершение запускается автоматически.

## 13. Тарифы

| Элемент | Действие |
|---|---|
| **Ежемесячно** | Показывает месячные цены. |
| **Ежегодно** | Показывает годовую цену со скидкой. |
| **Кнопка тарифа** | Сейчас всегда переводит на регистрацию студента; оплата и активация тарифа ещё не подключены. |

## 14. ИИ-консультант

| Элемент | Действие |
|---|---|
| **Круглая кнопка чата** | Открывает или закрывает ИИ-консультанта. |
| **Крестик в заголовке** | Закрывает окно чата. |
| **Популярный вопрос** | Автоматически отправляет выбранный готовый вопрос. |
| **Кнопка отправки** | Отправляет введённое сообщение; заблокирована при пустом поле или во время ответа. |

## 15. Системные состояния

| Элемент | Действие |
|---|---|
| **Вернуться** на странице запрета доступа | Переводит пользователя в домашний раздел, соответствующий его роли. |
| **Действие в пустом состоянии** | Выполняет контекстное действие, например открывает создание первой вакансии. |

## Условные обозначения

- **Заблокированная кнопка** не отправляет повторный запрос и обычно означает, что не заполнены обязательные поля либо операция уже выполняется.
- **Кнопка со статусом загрузки** временно блокируется до завершения API-запроса.
- Внешние ссылки открываются в новой вкладке.
- Удаление аккаунта, резюме и других важных данных требует подтверждения браузера.
